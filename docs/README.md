# Agent Shadow Brain documentation

Use the workspace to review project memory, build context for a task, or follow recorded agent activity. The CLI and MCP service provide the same local memory and context capabilities for scripts and coding clients.

## Start here

| Guide | When to use it |
| --- | --- |
| [Quickstart](QUICKSTART.md) | Install 7.1.3, open the workspace, and build a pack from a first memory. |
| [Workspace guide](WORKSPACE.md) | Work with memory reviews, typed links, context budgets, live activity, feature settings, and the local API. |
| [Client integrations](INTEGRATIONS.md) | Set up MCP stdio and find the right skill layout for each client. |
| [Workflow skills](WORKFLOW_INTEGRATION.md) | Preview or install the six bundled skills for Codex, Claude Code, OpenCode, DeepSeek Harness, or a portable client. |
| [Showcase](SHOWCASE.md) | Explore screenshots of the workspace and watch the live operations demo. |

## Connect and operate

- [Connect a coding client](INTEGRATIONS.md) for MCP stdio, context packs, and project capability checks.
- [Review and connect memories](WORKSPACE.md#review-and-connect-memories) from the workspace or with `shadow-brain curate`.
- [Follow live operations](WORKSPACE.md#follow-live-operations) and inspect measured or host-reported activity.
- [Change runtime controls](WORKSPACE.md#change-the-runtime-controls) through Features or the CLI.
